# 绘灵工作台视觉调整

用户已选择并批准「简洁专业」：浅灰侧栏、白色对话区、少量橙色点缀，统一首页与两个助手页面。

## 设计

- 侧栏收窄到 248px，保留折叠、历史筛选、改名、删除、账号与连接状态。移除底部装饰文案，给历史列表更多空间。
- 首页采用居中的欢迎区和两张简洁的助手卡片，移除营销插画、装饰英文与大面积渐变。
- 对话使用约 800px 的内容列；回复去掉外框，使用系统无衬线字体和清晰的标题、列表、表格层级。用户消息使用浅灰背景。
- 工具结果使用淡灰区域，保留可读操作名称、正文、展开、复制与下载。最终回答保持完整展开。
- 输入框压缩空白，保留发送、停止、补充回答、字数提示。上下文与会话 ID 收为次级信息，不新增未接入的按钮。
- 手机保持现有抽屉导航和焦点约束，输入框可见，代码和表格在内容区域内滚动。

## 实施顺序

1. 调整现有模板，统一全局样式变量与组件规则，删除被替换的装饰样式。
2. 增加工具结果的视觉分类，复用现有内容处理和下载逻辑。
3. 运行现有前端测试与构建，在模拟接口下检查真实页面和交互。

## 验收

覆盖首页、两个助手欢迎页、长回复、工具执行、PDF 下载、代码复制、流式响应、停止、历史记录和手机导航。检查 320–1920px 布局，无整页横向滚动，正文和输入框可读。测试不调用真实模型，不修改后端或用户聊天记录。
