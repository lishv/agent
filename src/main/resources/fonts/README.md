# PDF 中文字体

本目录包含 Noto Sans SC 的常规与粗体字重，供 PDF 生成工具通过资源流加载。字体随应用一起打包，无需依赖 Windows 或 Linux 的系统字体目录。

来源：

- https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC
- https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE

字体版权信息：Copyright 2014-2021 Adobe (http://www.adobe.com/).

字体文件未经修改，按 SIL Open Font License 1.1 分发，完整许可保存在本目录的 `OFL.txt`。使用其他字体时可通过 `pdf.fonts.regular` 和 `pdf.fonts.bold` 指定本地路径、`file:` URI 或 `classpath:` 资源。
